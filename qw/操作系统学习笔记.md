## 1. 环境准备
### 安装工具
```bash
# 安装汇编、调试与虚拟化工具
sudo pacman -S nasm gcc binutils qemu gdb
```

### 虚拟机配置
```bash
# 创建虚拟硬盘
dd if=/dev/zero of=disk.img bs=1M count=100

# 启动QEMU虚拟机（无GUI）
qemu-system-x86_64 -hda disk.img -boot a -nographic -serial
mon:iotty -monitor stdio
```

## 4. 入门示例
### Hello World汇编代码（用户模式）
```nasm
; hello.asm（用户模式）
global _start

extern printf

section .text
    mov rax, 0x4c000004  ; sys_write
    mov rdi, 1           ; 标准输出
    mov rsi, hello_msg
    mov rdx, 12
    syscall

hello_msg: db 'Hello!', 0xA, 0
```

## 5. 操作系统开发
### 引导程序示例
```nasm
; bootloader.asm
global _start

cli              ; 关闭中断
mov ax, 0x07e0
mov ds, ax
mov es, ax
mov [0x800], word 0x100000  ; 内核加载地址
```

### 内核模板
```nasm
; kernel.asm
_start:
    mov rax, 0x4c000004  ; sys_write
    mov rdi, 1           ; 标准输出
    mov rsi, kernel_msg
    mov rdx, kernel_msg_len
    syscall

kernel_msg: db 'Hello OS!', 0
kernel_msg_len: equ $-kernel_msg
```
