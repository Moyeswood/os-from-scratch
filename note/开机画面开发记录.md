# 开机画面（splash）开发记录

日期：2026-10-30。用户的 hello.asm（16 位实模式大字动画）美化 + 移植进内核作为开机画面。splash 套件 14 项 + 五套测试全量回归绿。

## 用户的原始程序

`helloworld/src/hello.asm`（用户手写，未改动）：实模式、模式 13h、自带 8×8 字模放大 4 倍的 "HELLO,WORLD!" 逐字动画、INT 1Ah 计时、颜色表洗牌、无限循环。结构清晰注释认真。

## 美化 + 移植

- **布局**（按用户意见定稿）：主标题 "HELLO WORLD"（11 个 32px 大字一行放不下 320 宽屏 → 拆 "HELLO" (y=28) / "WORLD" (y=76) 两行居中）+ 副标题 "NEWOS!"（16px 浅灰，y=132）+ **深蓝渐变星空背景**（60 颗星，滴答种子 LCG 每次开机位置不同）。
- **DAC 调色板编程**：0x10-0x1F 重定义为深蓝渐变 16 色（顶部亮 → 底部黑），背景每扫描行一个色（32 位写 4 像素加速）。
- **保留用户创意**：颜色表 + 洗牌逻辑原样保留（表首与随机位交换，种子改为 g_ticks）。
- **32 位移植**（`kernel/splash.asm`）：用户的 draw_big_char 逐字转保护模式——ES:DI 显存寻址 → 绝对地址 0xA0000+偏移，pusha/popa → pushad/popad，字体查找线性扫描原样；新增 M/y/Q/w/e/n/- 7 个同风格字形。
- **编排**（`kernel/splash.c`）：模式 13h 往返（跳板）→ 调色板 → 背景 → 逐字揭示（2 滴答/字）→ 停留 28 滴答 → 回文本模式 + 字体重应用。**任意键跳过**（8042 轮询）。总时长约 4 秒，开机不拖沓。
- **入口**：kernel_main 里 fs_init 之后 splash_run() + shell_reset_input()；另有 `splash` 命令可随时重放。

## 踩坑

1. **splash 命令的回车释放码被"任意键"吃掉** → 动画秒退（[SP] skipped）。修复：命令分支先 kbd_drain 再进动画。
2. **shell_discard_next_key 方案是错的**：预期 EOI 后 IRQ1 重投递跳过键会污染输入，实测加了丢弃标志后反而把下一条命令首字符吃掉（重投递读到的 8042 是空的，映射成 0x00 被忽略——和编辑器 Ctrl+X 的干净路径同款）。**kbd_drain + shell_reset_input 就够了**，丢弃标志删除。
3. 测试基建：批量给三个套件插 splash 等待时**插入点选在多行函数调用中间**把语法劈开（anchor 找到了 check 的第一行）→ 必须整块匹配再插。

## 测试（tools/test-splash.py，14 项）

启动自动播放（[SP] splash → done）/ 完成后 shell 可用 / splash 命令重放 / **任意键跳过 + 跳过键不污染输入**（pwd 干净）/ mkdir + 字体 + tetris 回归。其它四个套件 boot 段都加了 [SP] done/skipped 等待（开机画面的 4 秒会吃掉早到的按键）。
