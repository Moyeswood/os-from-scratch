## 移植方案（宏桥接，原版 528 行近乎逐字保留）

- 原版 github.com/rswier/c4：next() 词法 → expr() 优先级爬升 → stmt() → 栈式 VM eval()。
- **宏桥接**：`#define printf cc_printf` / `malloc cc_malloc` / `memset cc_memset` / `memcmp k_memcmp` / `open/read/close cc_open/cc_read/cc_close` / `exit(x) cc_exit(x)`——主体代码与原文逐字一致，适配全在桥接层。
- **cc_printf**：迷你 printf（%d 宽度零填充/%s/%c/%%），输出**屏幕 + 串口镜像**（串口是测试预言机）。
- **exit(-1) → `__builtin_longjmp`** 回 cc_run 的 setjmp 点（freestanding 无 libc setjmp；clang 要求 longjmp 参数为常量）。
- **VM 内存池**（sym/text/data/stack/heap 各 64KB）：memory.c 新增 **alloc_pages(n) 连续多页分配**（VM 池是连续地址空间，逐页 alloc_page 不保证连续！），用完逐页释放。
- **open/read/close 对接文件系统**：fd = inode 号，读取位置按 fd 记录——编译出的 C 程序能读 OS 里的文件（测试：C 程序 open+read 一个 echo 写出来的文件）。
- **ESC 失控保护**：VM 每 16384 条指令查一次 8042，ESC → "interrupted at cycle N" → 返回 shell（原版死循环只能整机复位）。
- 去掉原版 -s 源码回显/-d 调试（宿主机特性）；源文件上限 16KB；`#define int long long` 移除（32 位平台用原生 int）。

## 踩坑

1. `k_memset` 返回 void 而原版 memset 返回指针 → PRTF/MSET 行 `a = (int)memset(...)` 编译错 → 包一层返回指针的 cc_memset。
2. `close` 宏漏定义 → 隐式函数声明错误。
3. cc_printf 返回 void 而原版 printf 返回 int（PRTF 赋值用）→ 改 int。
4. 测试侧：**错误路径不打印 exit()**，run_cc 必须等具体错误串而不是统一等 exit(；echo 写文件带尾随 \n（read 返回 15 不是 14）。

## 2026-11-02 语言扩展：声明初始化 + for/do-while/break/continue

用户按标准 C 课程写 `int a = 5;` 和 for 循环时编译报错——c4 原版不支持。为让 cc 真正可用作课程练习环境，扩展了语法（commit 见 git log）：

- **声明初始化**（全局/局部）：`int a = 5;` 编译为 LEA/PSH/expr/SC/SI。全局初始化代码暂存 scratch，解析完拷到代码流末尾 + `JMP main`，执行入口改到那里（main 的 LEV 照常弹出 EXIT 哨兵，退出路径不变）。
- **for**：语法上增量子句在前、代码要放循环体后 → 增量代码暂存到 `cc_scratch[depth]`（**depth 在 body 解析期间保持占用**，内层 for 用更深一层才不互相覆盖），循环体后拷回；`i = (int)(e - sbase)` 长度计数、`*b = (int)(e + 1)` BZ 回填、continue 补丁到增量起点。
- **do-while / break / continue**：do 体先发码 + BNZ 回跳；break/continue 用 `cc_brk[]/cc_cnt[]` 补丁槽 + 每循环 save/restore 计数实现嵌套。

**踩的坑（都是真 bug，逐个定位）**：
1. **初始化代码排在 ENT 前**：函数入口 `id[Val] = e+1` 在声明解析前记录，而初始化代码在声明解析时发出 → 初始化跑在建帧前（写调用者栈）+ main 入口跳过它们。修：ENT 在声明解析**前**占位发出、声明完回填局部数。
2. **`next()` 越过 '=' 重解析右侧标识符，覆盖全局 `id`/`ty`** → `int b = a + 7;` 的 LEA 偏移取成 a 的槽位（b 的值写进 a），printf 参数同理。修：next() 前先存 `v = id[Val]`、`dty = ty`。
3. **scratch 差一**：`e = sc` 后首个 `*++e` 写到 sc[1]，长度/拷贝错位（执行入口读错字）。修：`e = sc - 1`，长度 = `e - (sc-1)`。

定位手段：VM 代码 dump（编译后把 `le[]` 前 64 字串口打印）+ 单行小程序二分（init→表达式→printf 参数逐层隔离）。局限（README 已注明）：暂存代码里的跳转（&& || ?:）拷回后目标失效。

测试：test-cc 扩到 40 项（init 全局/局部、for 求和、break/continue/嵌套 for、do-while、while+break），全绿。
